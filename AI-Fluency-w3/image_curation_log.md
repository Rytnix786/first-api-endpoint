## 🎯 2. Decision Rationale: Where Real Captures Win Over AI

### A. Code & Database Work (Real Capture Selected)
* **Decision:** Used a direct screenshot of VS Code displaying SQLite Viewer (`Task3-w3-a1/db_browser_screenshot.png`).
* **Why Real Capture:** AI-generated UI mockups of databases hallucinate fake code syntax, distorted text, and generic non-working interfaces. A crisp screenshot of my actual SQLite database proves that the backend endpoint is functioning and connected to real persistence storage.

### B. Personal Profile & Bio (Real Photo Selected)
* **Decision:** Used an authentic human photograph instead of an AI portrait avatar.
* **Why Real Photo:** AI-generated headshots look uncanny and corporate. A real photo conveys authenticity and personal responsibility for the work.
