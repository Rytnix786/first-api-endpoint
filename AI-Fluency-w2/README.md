# General AI Fluency - Week 2: Frame It As Cases

## 📌 Deliverable Overview
You need to create **one single document** containing:
1. **Voice Card** (at the top)
2. **Framed Case Studies** (for your internship projects / work pieces)
3. **Before / After Comparison** (Generic AI line vs. your edited, voice-driven line)

---

## 🎯 Step-by-Step Instructions

### Step 1: Voice Card (5 to 7 words)
Define how you want your writing to sound. 
*Example:* `Direct, warm, plain, no corporate buzzwords, conversational.`

### Step 2: Case Studies (3 Beats per piece)
For each project (e.g., your internship API/backend project in Task 1, Task 2, Task 3):
- **The Problem:** What specific challenge or need were you solving?
- **What You Did & Decided:** What technical decisions did you make? Why did you pick that approach over another?
- **What Came of It:** What was the result, metric, or outcome of the work?
- *(Include Bio & Contact/CTA copy at the bottom)*

### Step 3: Before vs. After Example
Provide one comparison showing generic AI text vs. your edited human version.
* Example **Generic AI:** *"Leveraged robust Python architecture to seamlessly optimize backend throughput."*
* Example **Edited Version:** *"Rebuilt the API routing using FastAPI so database queries execute 40% faster with clean error logs."*
